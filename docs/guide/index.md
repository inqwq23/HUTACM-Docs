## 简介

本指南主要帮助读者备战 12 月的校级程序设计竞赛，包含**计算机基础知识**、**C 语言基础语法**、**C++ 基本语法和 C++ STL**、**基础算法**和**练习指导**等知识的学习指导。

本指南的最佳学习时间是：**现在**。准确来说，从第一次看到这份指南的时间开始。越早开始学习这些知识，在我们的选拔中就更有优势。

为培养各位同学的自主学习能力，本学习指南只罗列了要学习的内容，提供学习方法的少量指导和一些相关资料，没有写具体的知识点。另一方面，网络上的相关学习资料丰富且优质，笔者没有必要在这里“重复造轮子”，也造不好。希望读者们能在本指南的引导下，锻炼出自学能力，更早地找到最适合自己的学习资料和学习方式。

本指南只是一份学习指导，记录了学长学姐的学习经验。希望同学们能找到更好的学习路线，也欢迎帮助我们改进这份学习指南。

从这里开始你的计算机大佬成长之路吧！
