[提问的智慧（*How To Ask Questions The Smart Way*）](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md)

为什么要特地放这一篇文章的链接在这里呢？

过去同学们在中学阶段，做题目遇到问题时，可以直接拿着作业本去教师办公室，与老师进行连续的线下交谈。但是在网上学习技能这种场景，往往只能通过文字方式表述问题，这需要提问者具有自行分析问题的主观能动性和清晰完整地描述问题的能力。即便在游戏社区中，这个逻辑同样适用。

《提问的智慧》这篇经典文章，不仅仅是教育读者怎样在网络社区中提问。它告诉我们在自学过程中，如何正确对待遇到的各种麻烦和疑问，学习这篇文章也是在提升自己的自学能力。
