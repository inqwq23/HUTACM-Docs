## 学习 C 程序设计语言

请读者通过观看视频课配合刷题的方式，学习 C 语言基础。这里推荐 **翁恺的 C 语言课程** ：[浙江大学翁恺教你C语言程序设计！C语言基础入门！](https://www.bilibili.com/video/BV1dr4y1n7vA/)  。

学习的时候一定要 **配合刷题** ，通过刷题的方式牢记用法，并感悟更多写法。切忌一次性学太多却不巩固之前的知识。具体的刷题教程请看 2.3 节。

**读者至少要学会以下语法知识：**

- 基本数据类型（整型、长整型、浮点数变量的声明、赋值等操作）
- 运算
- 输入和输出
- 顺序结构程序设计
- 选择结构程序设计
- 高级数据类型（数组、结构体）
- 循环结构程序设计
- 分支结构程序设计
- 函数的写法

**学习完以上知识需要约 2 周时间。**

务必配合翁恺的 C 语言课程学会以上基本语法知识，这些知识是接下来所有知识学习的基础。基本语法中，指针可以暂时不用学习，因为指针在面试和校赛中基本不需要使用。

> “学习的时候切记要刷题，手动实践。题目中自有黄金屋，很多奇妙的用法不刷题是学习不到的。而我们最终的比赛考核形式也是 **过题数** ，这些题目 **必定包含非常规的使用方法** ，因此要多加练习。”
> 
> ——2024 年招新文件《零基础学习指南》

## 刷题教程

从今开始的学习过程，我们默认同学们在下面所列的几个平台进行练习。练习时务必 **多看题解** ，学习别人的写法。

**洛谷**

初学时请选择 **红题（入门等级）** 练习。

https://www.luogu.com.cn/training/list

**牛客竞赛**

- **牛客 Tracker 可以作为刷题指南使用：[牛客 Tracker](https://www.nowcoder.com/problem/tracker#/daily) ，可以跟着技能树学习：[技能树](https://www.nowcoder.com/problem/tracker#/skill-tree) 。**
- [63天零基础入门编程-学习计划表](http://www.silencer76.com/strl/)
- 新手入门 130 题（**初学时做**）：https://www.nowcoder.com/exam/oj?page=1&tab=%E7%AE%97%E6%B3%95%E7%AF%87&topicId=383
- 算法入门题单 https://ac.nowcoder.com/discuss/817596
- 有基础的同学推荐精选题单 https://ac.nowcoder.com/discuss/926597
- 语法入门+算法入门题单：https://ac.nowcoder.com/discuss/817596

**HUTOJ**

HUTOJ 是我校学生自发创办的在线评测平台，收录了实验室近两年的面试和校程序设计竞赛真题，适合已经学得炉火纯青的同学提前感受我校的出题风格。自 2025 年 8 月起，实验室将不定期在此平台上举行不正式的训练赛，题目难度低，帮助大家巩固练习成果，熟悉面试/新生赛赛制。

https://acm.hut.edu.cn/
