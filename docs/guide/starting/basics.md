进入大学之前，同学们应该要熟悉计算机的基本使用，这比在上大学之前打暑假工增加阅历还要重要。如今，办公软件、AI 工具、线上协作软件在工作生活中被广泛应用，即使暂时不接触编程、3D 建模、仿真等高级工具，学会使用计算机仍然是同学们跟上时代的重要一步。在工科课程的平时上课中，也要频繁使用电脑进行仿真和实践操作。

跟着这份学习指南学习，尤其是要加入实验室的同学，必须要拥有一台属于自己的电脑。某些自媒体博主鼓吹“大一学生不要拥有电脑”，这种观念至少在计算机等工科专业是完全错误的。在工科大部分专业中，电脑是学生在课余时间进行实践学习必不可少的工具，工科专业注重实战经验，只有积累实际经验才能受到企业和研招院校的青睐。尤其在备战我们的新生赛的过程中，更是主要通过电脑进行练习。

工欲善其事，必先利其器。下面罗列的一些平时使用电脑时的基本操作，听起来似乎与我们接下来要学习的算法设计关系不大，实际上进行程序设计的时候，我们无法离开这些基本操作。另一方面，熟悉这些基本操作也便于后续理解专业软件的操作逻辑。
